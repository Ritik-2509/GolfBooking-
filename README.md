**About**
This project is a static website which uses HTML, CSS, and JavaScript to present an animated UI and booking-style interface for a turf/golf-booking scenario. It demonstrates front-end design, animations, and UX for selecting and booking slots.


**Features**

Animated UI: smooth transitions, hover effects, user-friendly interface

Responsive layout (works on desktop and mobile)

Booking form – simple UI to select date/time/slots (client-side only)

Clean design with CSS + animations

Easy to deploy (just open index.html)



**Built With**

HTML5

CSS3 (animations, transitions)

JavaScript (to handle booking form interactions)

(Optional) Any CSS frameworks if used — list them here if applicable

**Getting Started**
**Prerequisites**

You only need a modern web browser (Chrome / Firefox / Edge) — no server or database required since it’s static.

**Installation**

**Clone the repository:**

git clone https://github.com/Ritik-2509/GolfBooking-.git


**Change into the project directory:**

cd GolfBooking-


Open index.html in your browser to view the website.

**Usage**

Navigate to the website (open index.html).

Explore the home page, animations, and booking interface.

Use the booking form to pick a date and time slot (note: since this is static, the booking does not persist).

For deployment: you can host this via GitHub Pages, Netlify, or any static-web-hosting service.

**Folder Structure**
GolfBooking-/
├── index.html      ← The main HTML file  
├── style.css       ← The CSS stylesheet  
└── script.js       ← The JavaScript file handling UI/animation  


You can expand this structure (e.g., add assets/images, separate CSS/JS folders) as the project grows.
